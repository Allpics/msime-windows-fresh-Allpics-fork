快捷键
输入法快捷键仅在对应输入状态或候选窗口显示时生效。翻页方式可在“输入”中启用或关闭。
简繁切换
仅在中文输入状态生效，切换时保留正在输入的内容
中英文切换
勾选启用对应快捷键；Ctrl+Space 由 Windows 系统管理，此处不控制
开启后，上面勾选的快捷键按 中文 → 日文 → 英文 → 中文 依次切换；有输入时先上屏原始字母，中文和日文分别保留各自的输入方案
修改或关闭 Ctrl+Space（系统）
请前往 Windows 系统设置修改“输入法 / 非输入法切换”的按键顺序：
  1. 打开“设置”，进入“时间和语言” → “输入”。
  2. 选择“高级键盘设置” → “输入语言热键”。
  3. 选中“中文（简体）输入法 - 输入法 / 非输入法切换”，点击“更改按键顺序”。
  4. 关闭该按键顺序，或将 Ctrl+Space 改为其他不常用组合。
不同 Windows 版本的选项名称可能略有差异；修改后如未立即生效，请重新登录或重启电脑。
